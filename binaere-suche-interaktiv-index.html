6) Manuelle Runde 🎮

💡 Warum start = mitte + 1 oder ende = mitte - 1?

Wichtig: Die Mitte haben wir bereits geprüft! Sie ist nicht mehr im Suchbereich.

Beispiel: Liste [5, 10, 18, 20, 25, 39, 42, 50], suche 25

Schritt 1: Mitte = Index 3, Wert = 20

20 < 25 → Die Zahl muss rechts sein! Links von 20 (inklusive 20) können wir ausschließen.

→ start = mitte + 1 = 3 + 1 = 4 ✅

Schritt 2: Mitte = Index 5, Wert = 39

39 > 25 → Die Zahl muss links sein! Rechts von 39 (inklusive 39) können wir ausschließen.

→ ende = mitte - 1 = 5 - 1 = 4 ✅

    10) Dein Spickzettel 📌

    • Nur in sortierten Listen anwenden.
    • Mitte = int((Start + Ende) / 2)
    • Vergleich: kleiner → rechts abschneiden, größer → links abschneiden.
    • Stop: gefunden ODER Start > Ende.
    • Laufzeit: O(log n), weil der Suchraum halbiert wird.
    👍 Tipp: Erkläre die Methode jemand anderem. Wenn du es erklären kannst, hast du es verstanden!
