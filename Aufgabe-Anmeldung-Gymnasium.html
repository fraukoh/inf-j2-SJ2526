Aufgabe: Anmeldung berufliches Gymnasium

In diesem Projekt soll überprüft werden, ob eine Anmeldung mit einem mittleren Bildungsabschluss an einem beruflichen Gymnasium in Baden-Württemberg möglich ist oder nicht. Die Bedingungen dafür lauten wie folgt: Abschlusszeugnis (Mittlerer Bildungsabschluss) der
Realschule, der zweijährigen Berufsfachschule, der Berufsaufbauschule oder der Werkrealschule mit einem Notendurchschnitt von mindestens 3,0 aus Deutsch, Mathematik und Englisch (kein Fach schlechter als Note ausreichend).

Erwartete Ausgabe:

Deutschnote:  3
Englischnote:  3
Mathematiknote:  3

Die Aufnahme ist möglich.

Lösung

▼ Lösung anzeigen
note_deutsch = int(input("Deutschnote: "))
note_englisch = int(input("Englischnote: "))
note_mathematik = int(input("Mathematiknote: "))
ist_zugelassen = False

if note_deutsch <= 4:
    if note_englisch <= 4:        
        if note_mathematik <= 4:
            if (note_deutsch + note_englisch + note_mathematik) / 3 <= 3:
                ist_zugelassen = True
if ist_zugelassen == True:
    print("Die Aufnahme ist möglich.")
else:
    print("Aufnahme ist nicht möglich.")
