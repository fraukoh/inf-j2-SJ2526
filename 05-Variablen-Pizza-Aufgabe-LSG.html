Aufgabe:

Schreiben Sie ein Programm, das die Daten einer Pizza-Bestellung in mehreren Variablen speichert und hinterher ausgibt.

Stellen Sie sich vor, Sie bestellen mit Freunden Pizza. Gespeichert werden sollen: Name des Bestellers, Lieblingspizza, Anzahl der Pizzen, Preis pro Pizza, extra Käse (True/False) und Lieferung (True/False).

Diese Daten sollen dann im Browser ausgegeben werden.

Welche Eigenschaften haben die Ausgabedaten? (Variablenliste)

Bedeutung Inhalt Variablenname
Name des Bestellers Zeichenkette name
Lieblingspizza Zeichenkette pizza
Anzahl der Pizzen Ganzzahl anzahl
Preis pro Pizza Dezimalzahl preis_pro_pizza
Extra Käse? Wahrheitswert extra_kaese
Lieferung? Wahrheitswert lieferung

Erwartete Ausgabe:

Besteller: Alex
Pizza: Margherita
Anzahl: 3
Preis pro Pizza: 9.5 €
Extra Käse: True
Lieferung: False

Lösung

▼ Lösung anzeigen
#Hier den Programmcode eingeben und mit STRG+ENTER ausführen
# Deklaration und Initialisierung der Variablen:
name = "Alex"
pizza = "Margherita"
anzahl = 3
preis_pro_pizza = 9.5
extra_kaese = True
lieferung = False

# Ausgabe:
print("Besteller:", name)
print("Pizza:", pizza)
print("Anzahl:", anzahl)
print("Preis pro Pizza:", preis_pro_pizza, "€")
print("Extra Käse:", extra_kaese)
print("Lieferung:", lieferung)
